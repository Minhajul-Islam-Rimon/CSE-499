# IEEE LaTeX Paper

Upload this entire directory to Overleaf and set `main.tex` as the main document. Compile with pdfLaTeX; BibTeX is used automatically by Overleaf for `references.bib`.

Project contents:

- `main.tex`: complete IEEE two-column paper
- `references.bib`: the thesis reference list in BibTeX form
- `figures/`: original thesis figures extracted from the editable thesis source
- `conversion_report.md`: retained/removed content and exact-transfer notes
- `main.pdf`: locally compiled and visually verified 14-page output
